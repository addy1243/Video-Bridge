Download the **VideoBridge-…-Setup-x64.exe** asset below for Windows 10/11 x64.

Python, Node.js, FFmpeg, and downloader dependencies are included. No separate prerequisite installs or administrator rights are required. Close browser windows and active downloads before installing or updating.

After installation, leave **Connect the extension to Chrome or Edge** checked. Follow the instructions to enable Developer mode, load the installed extension folder, and paste its extension ID. Chrome and Edge require this browser step; the installer cannot silently add an unpacked extension.

Downloader updates remain available inside the extension. Future extension/runtime releases require running the newer installer and reloading the extension. Existing download files are preserved. To add another browser, run **Connect VideoBridge to browser** from the Start menu again.

This first installer is unsigned, so Windows may show an unknown-publisher/SmartScreen warning. Check that the download came from this repository. SHA256SUMS.txt is provided for integrity checking. The installer does not include an uninstaller; remove the extension in your browser before manually removing the installed folder if no longer needed.

Broad website support varies. DRM-protected media cannot be exported. Use content you have permission to save.
